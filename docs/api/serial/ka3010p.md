# KA3010P

Programmable DC Power Supply with RS-232 serial connectivity.

## Device Specifications

| Parameter | Specification |
|-----------|---------------|
| Model | Korad KA3010P |
| Voltage Range | 0-30V |
| Current Range | 0-10A |
| Interface | RS-232 serial |
| Power Rating | 300W |

## Overview

The KA3010P driver provides full control of the Korad KA3010P single-output programmable DC power supply. This is a popular benchtop supply offering higher current capacity (10A) than the DP711.

## Quick Start

```python
from lab_drivers.drivers.serial import KA3010P

# Auto-connect to KA3010P
psu = KA3010P()

# Set output 12V @ 2A
psu.set_voltage(12.0)
psu.set_current(2.0)
psu.set_output_state(True)

# Read measurements
v = psu.measure_voltage()
i = psu.measure_current()
print(f"Output: {v:.2f}V @ {i:.3f}A")

# Enable output
psu.set_output_state(True)

# Disable output
psu.set_output_state(False)
psu.disconnect()
```

## Supported Commands

| Command | Function | Returns |
|---------|----------|---------|
| `set_voltage(v)` | Set output voltage (V) | - |
| `set_current(i)` | Set current limit (A) | - |
| `measure_voltage()` | Read actual voltage | float (V) |
| `measure_current()` | Read actual current | float (A) |
| `set_output_state(state)` | Enable/disable output | - |
| `get("voltage")` | Generic voltage getter | float (V) |
| `get("current")` | Generic current getter | float (A) |
| `get("VOLT")` | SCPI-style voltage getter | float (V) |
| `get("CURR")` | SCPI-style current getter | float (A) |

## Connection Methods

### Auto-Detection
```python
psu = KA3010P()  # Auto-finds first available KA3010P
```

### Explicit COM Port
```python
psu = KA3010P(com_port="/dev/ttyUSB0")  # Linux/macOS
psu = KA3010P(com_port="COM4")          # Windows
```

### Specify Baud Rate
```python
psu = KA3010P(baud_rate=9600)  # Default is 9600
```

## Usage Patterns

### Constant Power Load
```python
psu = KA3010P()
psu.set_voltage(12.0)
target_power = 100  # 100W

for i in range(20):
    psu.set_current(target_power / 12.0)
    v = psu.measure_voltage()
    i = psu.measure_current()
    p = v * i
    print(f"Power: {p:.1f}W")
    time.sleep(0.5)

psu.disconnect()
```

### Battery Charging Simulation
```python
psu = KA3010P()
psu.set_current(5.0)  # 5A charge current limit
psu.set_output_state(True)

voltages = [4.2, 8.4, 12.6, 25.2]  # For 1S, 2S, 3S, 6S batteries
for battery_volts in voltages:
    psu.set_voltage(battery_volts)
    print(f"Charging at {battery_volts}V...")
    time.sleep(10)

psu.set_output_state(False)
psu.disconnect()
```

### Output Ripple Monitoring
```python
psu = KA3010P()
psu.set_voltage(5.0)
psu.set_current(2.0)
psu.set_output_state(True)

# Monitor voltage stability
readings = []
for _ in range(100):
    v = psu.measure_voltage()
    readings.append(v)
    time.sleep(0.1)

avg = sum(readings) / len(readings)
ripple = max(readings) - min(readings)
print(f"Average: {avg:.4f}V, Ripple: {ripple:.4f}V")

psu.disconnect()
```

## Specifications & Limits

- **Voltage Setting**: 0.0V to 30.0V (0.1V resolution)
- **Current Setting**: 0.0A to 10.0A (0.1A resolution)
- **Overvoltage Protection**: ~33V (auto shutdown)
- **Overcurrent Protection**: Configurable
- **Cooling**: Active cooling (fan)
- **Stability**: <1% voltage regulation

## Troubleshooting

### "Device not found"
- Check USB connection
- Verify device is powered on
- List ports with: `python -m serial.tools.list_ports`
- Try explicit COM port: `KA3010P(com_port="COM3")`

### Measurements don't update
- Wait 100ms between commands
- Verify output is enabled: `set_output_state(True)`
- Check for communication errors

### Voltage/current not setting
- Verify these are floating-point values: `set_voltage(12.0)` not `set_voltage(12)`
- Check that values are within limits (0-30V, 0-10A)
- Try power cycling the device

# RSA3030

Rigol RSA3030-TG Spectrum Analyzer with SCPI control via USB or Ethernet.

## Device Specifications

| Parameter | Specification |
|-----------|---------------|
| Model | Rigol RSA3030-TG |
| Frequency Range | 100 kHz - 3 GHz |
| Span | 0 Hz (zero span) to 3 GHz |
| Resolution Bandwidth | 1 Hz to 3 MHz |
| Sweep Time | 1 ms to 1000 s |
| Interface | USB, Ethernet (VISA) |
| Memory | 16 GB internal storage |

## Overview

The RSA3030 driver provides complete SCPI-based control of the Rigol RSA3030-TG spectrum analyzer with auto-detection via USB or Ethernet (including link-local discovery).

## Quick Start

```python
from lab_drivers.drivers.visa import RSA3030

# Auto-connect (scans VISA resources + link-local IPs)
spectrum = RSA3030()

# Get device identification
identity = spectrum.get_identity()
print(f"Connected to: {identity}")

# Configure for waveform capture
spectrum.configure_spectrum(
    center_freq=2.4e9,    # 2.4 GHz WiFi
    span=100e6,           # 100 MHz span
    rbw=1e6,              # 1 MHz RBW
    vbw=1e6               # 1 MHz VBW
)

# Capture spectral data
data = spectrum.capture_spectrogram(filename="spectrum.csv")
print(f"Captured {data['points']} points")
print(f"Peak power: {max(data['amplitude']):.2f} dBm")

spectrum.disconnect()
```

## Supported Commands

| Command | Function | Returns |
|---------|----------|---------|
| `get_identity()` | Get device identification | str |
| `configure_spectrum(...)` | Set spectrum analyzer parameters | - |
| `capture_spectrogram()` | Capture spectrum data to file | dict |
| `capture_trace(trace_number)` | Get waveform trace data | (freqs, amplitudes) |
| `get("identity")` | Generic identity getter | str |
| `_query(cmd)` | Send SCPI query | str |
| `_write(cmd)` | Send SCPI command | - |

## Connection Methods

### Auto-Detection (Recommended)
```python
# Scans VISA resources and link-local IPs
spectrum = RSA3030()
```

### USB Connection
```python
spectrum = RSA3030(address="USB0::0x1AB1::0x0960::RSA3XXXXXXXX::INSTR")
```

### Ethernet Connection via IP
```python
spectrum = RSA3030(ip_address="192.168.1.100")
```

### Ethernet Connection via VISA Address
```python
spectrum = RSA3030(address="TCPIP0::192.168.1.100::INSTR")
```

### Explicit Address without Auto-Connect
```python
spectrum = RSA3030(auto_connect=False)
spectrum.connect(address="USB0::...")
```

## Configuration

### Spectrum Configuration
```python
spectrum = RSA3030()

spectrum.configure_spectrum(
    center_freq=1e9,      # 1 GHz center frequency
    span=500e6,           # 500 MHz span (1 GHz to 1.5 GHz)
    rbw=10e3,             # 10 kHz resolution bandwidth
    vbw=10e3              # 10 kHz video bandwidth
)

spectrum.disconnect()
```

### Zero-Span Measurement (Time Domain)
```python
spectrum = RSA3030()

# Configure for zero-span (constant frequency, time domain)
spectrum.configure_spectrum(
    center_freq=2.4e9,    # 2.4 GHz
    span=0,               # Zero span = time domain
    rbw=1e6,              # RBW affects demod bandwidth
    vbw=1e6
)

data = spectrum.capture_trace(trace_number=1)
spectrum.disconnect()
```

## Data Capture

### Capture to File
```python
spectrum = RSA3030()
spectrum.configure_spectrum(center_freq=1e9, span=100e6, rbw=1e3, vbw=1e3)

data = spectrum.capture_spectrogram(filename="capture_2024_03_20.csv")
print(f"Saved {data['points']} points to capture_2024_03_20.csv")
print(f"Frequency range: {data['start_freq']/1e9:.3f} - {data['stop_freq']/1e9:.3f} GHz")

spectrum.disconnect()
```

### Get Trace Data
```python
spectrum = RSA3030()
spectrum.configure_spectrum(center_freq=2.4e9, span=200e6, rbw=100e3, vbw=100e3)

# Capture and get arrays directly
freqs, amps = spectrum.capture_trace(trace_number=1)
peak_idx = amps.index(max(amps))
peak_freq = freqs[peak_idx]
print(f"Peak at {peak_freq/1e9:.4f} GHz: {amps[peak_idx]:.2f} dBm")

spectrum.disconnect()
```

## Usage Patterns

### WiFi Channel Analysis
```python
spectrum = RSA3030()

# WiFi 2.4 GHz band (2.4-2.5 GHz)
wifi_channels = {
    1: 2.412e9,
    6: 2.437e9,
    11: 2.462e9
}

for ch, freq in wifi_channels.items():
    spectrum.configure_spectrum(
        center_freq=freq,
        span=40e6,  # 40 MHz span
        rbw=300e3
    )
    data = spectrum.capture_spectrogram(filename=f"wifi_ch{ch}.csv")
    print(f"WiFi CH{ch}: {max(data['amplitude']):.2f} dBm")

spectrum.disconnect()
```

### Interference Hunting
```python
spectrum = RSA3030()

# Scan frequency bands for interference
bands = [
    ("915 MHz ISM", 902e6, 928e6),
    ("2.4 GHz ISM", 2400e6, 2500e6),
    ("5 GHz WiFi", 5000e6, 6000e6)
]

for name, start, stop in bands:
    spectrum.configure_spectrum(
        center_freq=(start + stop) / 2,
        span=stop - start,
        rbw=1e6
    )
    data = spectrum.capture_spectrogram()
    peak = max(data['amplitude'])
    print(f"{name}: Peak {peak:.2f} dBm")

spectrum.disconnect()
```

## Specifications & Performance

- **Frequency Accuracy**: ±50 ppm
- **Sweep Time**: 1 ms to 1000 s per sweep
- **Display Points**: Up to 8000 (typically 601)
- **USB Speed**: Full-speed USB, may limit data transfer rate
- **Ethernet**: 1 Gbps capable
- **Power Consumption**: ~100W typical

## Troubleshooting

### "No RSA3030 found"
- Check USB connection or Ethernet connectivity
- List available VISA resources: `pyvisa ResourceManager().list_resources()`
- Try explicit IP address if Ethernet device

### Spectrum data looks wrong
- Verify center frequency and span are set correctly
- Check RBW/VBW settings (wider = faster, narrower = more detail)
- Ensure antenna is connected properly

### Slow data capture
- Reduce number of sweep points if possible
- Increase RBW/VBW for faster sweeps
- Check Ethernet connection speed (1GB preferred)

## SCPI Command Reference

For direct SCPI access, use `_query()` and `_write()`:

```python
spectrum = RSA3030()

# Example: Set frequency directly
spectrum._write("SENS:FREQ:CENT 1GHz")
spectrum._write("SENS:FREQ:SPAN 100MHz")

# Query frequency
freq = spectrum._query("SENS:FREQ:CENT?")
print(f"Center: {float(freq):e} Hz")

spectrum.disconnect()
```

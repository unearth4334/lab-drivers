# DL3021

Programmable DC Electronic Load with VISA connectivity.

## Device Specifications

| Parameter | Specification |
|-----------|---------------|
| Model | DL3021 |
| Max Power | 150W |
| Load Modes | CC (current), CV (voltage), CR (resistance), CP (power) |
| Voltage Range | 0-80V |
| Current Range | 0-80A |
| Interface | VISA (USB, GPIB) |
| Accuracy | ±0.5% of range |

## Overview

The DL3021 driver provides comprehensive control of the programmable electronic load for power supply testing, battery characterization, and component validation.

## Quick Start

```python
from lab_drivers.drivers.visa import DL3021

# Auto-connect to electronic load
load = DL3021()

# Constant current mode
load.set_mode("CC")
load.set_current(5.0)  # 5A load

# Enable load
load.set_output_state(True)

# Monitor power supply under load
voltage = load.measure_voltage()
current = load.measure_current()
power = load.measure_power()
print(f"V: {voltage:.2f}V, I: {current:.3f}A, P: {power:.2f}W")

# Disable load
load.set_output_state(False)
load.disconnect()
```

## Supported Commands

| Command | Function | Returns |
|---------|----------|---------|
| `set_mode(mode)` | Set load mode (CC/CV/CR/CP) | - |
| `set_current(i)` | Set constant current value (A) | - |
| `set_voltage(v)` | Set constant voltage value (V) | - |
| `set_resistance(r)` | Set constant resistance value (Ω) | - |
| `set_power(p)` | Set constant power value (W) | - |
| `measure_voltage()` | Measure input voltage | float (V) |
| `measure_current()` | Measure load current | float (A) |
| `measure_power()` | Measure consumed power | float (W) |
| `set_output_state(state)` | Enable/disable load | - |
| `get(item)` | Generic getter | varies |

## Load Modes

### Constant Current (CC)
Most common mode for power supply testing:

```python
load = DL3021()
load.set_mode("CC")
load.set_current(10.0)  # 10A constant load
load.set_output_state(True)

# Power supply responds with constant 10A regardless of voltage
voltage = load.measure_voltage()
print(f"Supply voltage under 10A load: {voltage:.2f}V")

load.disconnect()
```

### Constant Voltage (CV)
For battery characterization or testing regulators:

```python
load = DL3021()
load.set_mode("CV")
load.set_voltage(12.0)  # Load increases until 12V across it
load.set_output_state(True)

# Current increases to maintain 12V across load
current = load.measure_current()
print(f"Current: {current:.3f}A")

load.disconnect()
```

### Constant Resistance (CR)
For simulating fixed load (like resistive heating):

```python
load = DL3021()
load.set_mode("CR")
load.set_resistance(10.0)  # 10Ω load equivalent to V = I*R
load.set_output_state(True)

power = load.measure_power()
print(f"Power dissipated: {power:.2f}W")

load.disconnect()
```

### Constant Power (CP)
For testing power supply stability:

```python
load = DL3021()
load.set_mode("CP")
load.set_power(50.0)  # 50W constant load
load.set_output_state(True)

# As voltage changes, current adjusts to maintain 50W
voltage = load.measure_voltage()
current = load.measure_current()
actual_power = voltage * current
print(f"Power: {actual_power:.2f}W")

load.disconnect()
```

## Usage Patterns

### Power Supply Load Testing
```python
load = DL3021()
load.set_mode("CC")
load.set_output_state(True)

# Test at different current levels
for current_level in [1, 5, 10, 20, 30]:
    load.set_current(current_level)
    voltage = load.measure_voltage()
    power = load.measure_power()
    regulation = abs(voltage - 12.0) * 100 / 12.0  # Regulation %
    print(f "{current_level}A: {voltage:.3f}V, {power:.2f}W, Reg: {regulation:.2f}%")

load.disconnect()
```

### Battery Discharge Curve
```python
load = DL3021()
load.set_mode("CC")
load.set_current(5.0)  # 5A discharge rate
load.set_output_state(True)

import time
measurements = []
start_time = time.time()

while True:
    voltage = load.measure_voltage()
    current = load.measure_current()
    elapsed = time.time() - start_time
    
    if voltage < 2.5:  # Battery depleted
        break
    
    measurements.append((elapsed, voltage, current))
    time.sleep(1.0)

load.set_output_state(False)
load.disconnect()

# Plot discharge curve
print("Time(s) | Voltage(V) | Current(A)")
for t, v, i in measurements:
    print(f"{t:6.1f} | {v:6.2f} | {i:6.3f}")
```

### Thermal Stress Test
```python
load = DL3021()
load.set_mode("CP")
load.set_power(100.0)  # 100W constant power
load.set_output_state(True)

print("Monitoring for 10 minutes...")
for i in range(600):
    v = load.measure_voltage()
    i = load.measure_current()
    p = load.measure_power()
    
    if i > 0.1:  # Check for safe current limits
        print(f"{i/10}min: {v:.2f}V, {i:.2f}A, {p:.1f}W")
        time.sleep(10)
    else:
        print("Current limit exceeded, stopping test")
        break

load.set_output_state(False)
load.disconnect()
```

## Specifications

**Current Range**: 0-80A  
**Power Range**: 0-150W
**Resolution**: Typically 0.01V / 0.01A / 0.1W
**Accuracy**: ±0.5% of range ±5 digits
**Heat Dissipation**: Requires cooling (forced air recommended)

## Safety Considerations

- **Heat Generation**: 150W load can generate significant heat—ensure proper cooling
- **Protection**: Device has built-in overcurrent protection
- **Voltage Limits**: Some supplies may not handle CV mode at high voltages
- **Power Limits**: Monitor power dissipation—150W is the absolute maximum

## Troubleshooting

### "Load not found"
- Check VISA connection (USB or GPIB)
- List resources: `pyvisa ResourceManager().list_resources()`
- Try explicit VISA address

### "Cannot change mode"
- Some modes may have initialization delays (50-100ms)
- Try disabling output first: `set_output_state(False)`
- Then change mode and re-enable

### Measurements don't update
- Ensure output is enabled: `set_output_state(True)`
- Wait 100ms between commands
- Avoid rapid mode switching

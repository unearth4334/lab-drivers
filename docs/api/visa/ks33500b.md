# KS33500B

Keysight 33500B Series Function/Arbitrary Waveform Generator with VISA control.

## Device Specifications

| Parameter | Specification |
|-----------|---------------|
| Model | Keysight 33500B (33522B for dual-channel) |
| Channels | 1 or 2 (depending on model) |
| Frequency Range | 1 μHz to 30 MHz |
| Waveforms | Sine, Square, Triangle, Ramp, Pulse, Noise, DC |
| Amplitude Range | 1 mV to 10 V (into 50Ω) |
| Modulation | AM, FM, PM, FSK, PWM, sweep |
| Arbitrary Waveforms | 1 MSa per channel memory |
| Interface | USB, GPIB, LAN (VISA) |
| Accuracy | <100 ppm frequency accuracy |

## Overview

The KS33500B driver provides comprehensive control of the Keysight 33500B series waveform generator for signal creation, modulation, and frequency sweeping applications.

## Quick Start

```python
from lab_drivers.drivers.visa import KS33500B

# Auto-connect to waveform generator
wfg = KS33500B()

# Configure channel 1 for sine wave
wfg.set_function("SIN", channel=1)
wfg.set_frequency(1000.0, channel=1)  # 1 kHz
wfg.set_amplitude(2.0, channel=1)     # 2 Vpp
wfg.set_offset(0.0, channel=1)        # 0V offset

# Enable output
wfg.set_output_state(True, channel=1)

# Configure channel 2 for square wave (dual-channel models)
wfg.set_function("SQU", channel=2)
wfg.set_frequency(500.0, channel=2)   # 500 Hz
wfg.set_amplitude(1.5, channel=2)     # 1.5 Vpp
wfg.set_duty_cycle(30.0, channel=2)   # 30% duty cycle

# Enable output
wfg.set_output_state(True, channel=2)

wfg.disconnect()
```

## Supported Commands

| Command | Function | Returns |
|---------|----------|---------|
| `set_function(func, channel)` | Set waveform type | - |
| `set_frequency(freq, channel)` | Set frequency (Hz) | - |
| `set_amplitude(amp, channel)` | Set amplitude (Vpp) | - |
| `set_offset(offset, channel)` | Set DC offset (V) | - |
| `set_duty_cycle(duty, channel)` | Set duty cycle (%) | - |
| `set_pulse_width(width, channel)` | Set pulse width (seconds) | - |
| `set_symmetry(sym, channel)` | Set symmetry (%) | - |
| `enable_modulation(mod_type, ...)` | Enable modulation | - |
| `set_output_state(state, channel)` | Enable/disable output | - |
| `get(item)` | Generic getter | varies |

## Waveform Types

### Sine Wave (SIN)
Classic sine wave output:

```python
wfg = KS33500B()
wfg.set_function("SIN", channel=1)
wfg.set_frequency(10000.0)    # 10 kHz
wfg.set_amplitude(2.0)        # 2 Vpp
wfg.set_offset(1.0)           # 1V DC offset
wfg.set_output_state(True, channel=1)
wfg.disconnect()
```

### Square Wave (SQU)
Digital-friendly square wave with adjustable duty cycle:

```python
wfg = KS33500B()
wfg.set_function("SQU", channel=1)
wfg.set_frequency(1000.0)     # 1 kHz
wfg.set_amplitude(3.3)        # 3.3V for logic levels
wfg.set_duty_cycle(50.0)      # 50% duty (symmetric)
wfg.set_output_state(True, channel=1)
wfg.disconnect()
```

### Triangle Wave (TRI)
Linear ramping triangle for testing:

```python
wfg = KS33500B()
wfg.set_function("TRI", channel=1)
wfg.set_frequency(500.0)      # 500 Hz
wfg.set_amplitude(4.0)        # 4 Vpp
wfg.set_symmetry(50.0)        # 50% = symmetric triangle
wfg.set_output_state(True, channel=1)
wfg.disconnect()
```

### Ramp Wave (RAMP)
Rising or falling sawtooth:

```python
wfg = KS33500B()
wfg.set_function("RAMP", channel=1)
wfg.set_frequency(100.0)      # 100 Hz
wfg.set_amplitude(5.0)        # 5 Vpp
wfg.set_symmetry(100.0)       # 100% = full rising ramp
wfg.set_output_state(True, channel=1)
wfg.disconnect()
```

### Pulse Wave (PULS)
Configurable pulse width:

```python
wfg = KS33500B()
wfg.set_function("PULS", channel=1)
wfg.set_frequency(1000000.0)    # 1 MHz
wfg.set_amplitude(3.3)          # 3.3V logic level
wfg.set_pulse_width(50e-9)      # 50 nanosecond pulse
wfg.set_output_state(True, channel=1)
wfg.disconnect()
```

## Modulation

### Amplitude Modulation (AM)
Vary amplitude at modulation frequency:

```python
wfg = KS33500B()
wfg.set_function("SIN", channel=1)
wfg.set_frequency(10000.0)      # 10 kHz carrier
wfg.set_amplitude(2.0)          # 2 Vpp

# AM: 50% depth at 1 kHz modulation rate
wfg.enable_modulation("AM", depth=50.0, freq=1000.0, channel=1)
wfg.set_output_state(True, channel=1)
wfg.disconnect()
```

### Frequency Modulation (FM)
Sweep frequency around carrier:

```python
wfg = KS33500B()
wfg.set_function("SIN", channel=1)
wfg.set_frequency(100000.0)     # 100 kHz carrier
wfg.set_amplitude(1.0)

# FM: ±500 Hz deviation at 100 Hz mod rate
wfg.enable_modulation("FM", deviation=500.0, freq=100.0, channel=1)
wfg.set_output_state(True, channel=1)
wfg.disconnect()
```

### Phase Modulation (PM) / Frequency Sweep (FMCW)
Chirp signal for radar/LiDAR emulation:

```python
wfg = KS33500B()

# Linear FM chirp: 100 MHz to 200 MHz over 1 second
wfg.enable_modulation(
    "FM",
    deviation=50e6,  # ±50 MHz deviation
    freq=1.0,        # 1 Hz (1 second period)
    channel=1
)
wfg.set_output_state(True, channel=1)
wfg.disconnect()
```

## Multi-Channel Operation

Control two independent channels (33522B models):

```python
wfg = KS33500B()

# Configure channels with phase offset
wfg.set_function("SIN", channel=1)
wfg.set_frequency(1000.0, channel=1)
wfg.set_amplitude(2.0, channel=1)
wfg.set_phase(0.0, channel=1)      # 0° phase

wfg.set_function("SIN", channel=2)
wfg.set_frequency(1000.0, channel=2)
wfg.set_amplitude(2.0, channel=2)
wfg.set_phase(90.0, channel=2)     # 90° phase (quadrature)

wfg.set_output_state(True, channel=1)
wfg.set_output_state(True, channel=2)

wfg.disconnect()
```

## Usage Patterns

### Frequency Sweep
```python
wfg = KS33500B()
wfg.set_function("SIN", channel=1)
wfg.set_amplitude(1.0, channel=1)
wfg.set_output_state(True, channel=1)

# Manual frequency sweep
freqs = [100, 200, 500, 1000, 2000, 5000, 10000]
for freq in freqs:
    wfg.set_frequency(freq, channel=1)
    print(f"Frequency: {freq} Hz")
    time.sleep(0.5)

wfg.disconnect()
```

### Pulse Train for QA Testing
```python
wfg = KS33500B()
wfg.set_function("PULS", channel=1)
wfg.set_frequency(100.0)          # 100 Hz pulse rate
wfg.set_amplitude(5.0)            # 5V logic level
wfg.set_pulse_width(100e-6)       # 100 microsecond pulses
wfg.set_output_state(True, channel=1)

print("Applying 100 Hz pulse train for 60 seconds...")
time.sleep(60)

wfg.set_output_state(False, channel=1)
wfg.disconnect()
```

## Troubleshooting

### "Waveform generator not found"
- Check USB/GPIB/Ethernet connection
- List resources: `pyvisa ResourceManager().list_resources()`
- Try explicit VISA address

### Output not appearing
- Verify `set_output_state(True, channel=1)` is called
- Check amplitude is non-zero
- Verify output impedance match (50Ω) if needed

### Frequency not changing
- Ensure frequency is within range (1 μHz - 30 MHz)
- Disable modulation if interfering: `set_modulation("OFF", channel=1)`
- Try explicit channel parameter

### Modulation depth/deviation too large
- Device limits modulation to reasonable values
- Reduce depth/deviation parameter
- Check instrument manual for limits
